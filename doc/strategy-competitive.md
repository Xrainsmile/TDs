# 战略路线与竞品分析：决策方法 / 赛道判断 / 爽点拆解

本文档记录玩法与方向层面的讨论结论（美术相关见 `art-pipeline.md`），回答三个问题：**个人开发者怎么做决策、现在进塔防赛道是不是红海、怎么让游戏更好玩**。

> **已确认的项目目标**：不是自娱自乐，是"让更多人玩"。这一个答案自动排出后面所有事情的优先级。

---

## 一、决策方法：个人开发者不需要"决策所有的东西"

决策疲劳的根源是把三类不同的决策混在一起。正确做法是分类处理：

| 类别 | 含义 | 处理方式 | 本项目实例 |
|---|---|---|---|
| **A 类：北极星决策** | 只有作者能拍，无标准答案，但也无时间压力（可能就 3~5 个） | 想清楚一次，管几个月 | 游戏给谁玩、核心乐趣是什么（Build 构筑肉鸽塔防）、目标（让更多人玩） |
| **B 类：可抄的成熟范式** | 塔防是被验证过几百遍的品类：数值框架、经济循环、UI 布局、波次节奏…… | **先抄后调**：找最接近目标的参考游戏照搬结构，哪里不爽改哪里 | `tower-defense-balance-4s.md` 的 4 秒击杀基准就是这么来的 |
| **C 类：可推迟的决策** | 看起来很急，但正确决策依赖"玩法先跑起来"这个事实 | **不决策，只定触发条件**；等信息长出来 | 美术引入时机、平衡数值、多关卡设计 |

两个落地技巧：

- **把决策换成触发条件**：纠结"什么时候做"最消耗人。例如美术节奏没有定日期，而是定了一组触发信号（卡牌编译通过→管线验证；试玩前→UI；玩法冻结→批量生产），接下来几个月都不用再想，信号出现才花精力。此模式可推广到所有 C 类决策。
- **开放问题先收敛再拍板**：遇到拿不准的事，把问题收成 2~3 个带利弊和推荐的选项再选；并永远可以追问"这个能不能抄？能不能推迟？"——大多数时候答案是能。

`tower-defense-roadmap-18.md` 本质上就是一份决策排程表（每阶段自带目标/验证点/通过标准），信任它顺着走，不用每一步重新焦虑"现在该干什么"。

## 二、赛道判断：对你不是红海

**问题本身问错了主语。** "红海"通过特定机制生效：花钱买量 → 回收不了 → 亏损出局。它屠杀的是靠投放活着的公司，不是零投放的个人开发者。

### 市场事实（2026 年微信小游戏官方大会数据，双面都摆）

"是红海"的论据：
- 开发者总数超 50 万；2025 年增速 34.39%，较爆发期放缓；畅销榜头部被大厂产品占据。

"不是红海"的论据（更硬）：
- 官方大会直接把**"放置、塔防"列为蓝海阶段品类**（原话"放置、塔防等大盘赛道潜力未挖"）；
- 塔防在畅销榜的席位还在增加（《保卫向日葵》回归、《城主别慌张》空降 Top20）；
- 年流水破百万的 IAA 产品超 **1400 款**，IAA 月活 4 亿——这是留给中小开发者的空间；
- 平台扶持期：IAP 首发 5000 万流水不分成、新游专区帮扶；开发者中八成是不足 30 人的中小团队。

### 个人开发者 vs 公司的成本结构

| | 公司 | 个人开发者 |
|---|---|---|
| 获客方式 | 买量（CPI 越来越高 → 绞肉机） | 自然量 + 社交裂变（免费） |
| 失败代价 | 真金白银亏损 | 业余时间 |
| 活下去的门槛 | 月流水千万级养团队 | 月流水几万即是副业成功 |

**同一片市场，对投放公司是红海，对零投放的个人开发者可以是蓝海。**

### 真正的筛选器是辨识度，不是品类

死掉的成千上万款产品，死因不是"进了塔防赛道"，而是"30 秒内看不出和别人的区别"：

- 做"又一个换皮塔防" → 必死，哪年做都死；
- 做"一句话能说清差异的塔防" → 品类拥挤度与你无关，5 亿月活大盘还在涨。

本项目的差异雏形：**"词条化学反应的肉鸽塔防"**——Build 深度恰是头部竞品没有的一层。

### 红海焦虑的隐蔽危害

它会让人在做到一半时提前放弃——而"做完"恰恰是个人开发者最大的壁垒。真正值得焦虑的三件事：**做不完**（第一死因）、**做出来无差异**（第二死因）、**上线后数据差但不知道为什么**（没有验证埋点）。

## 三、"好玩"的解剖：五个支柱

"更多人玩"是乘法公式：**吸量（题材/图标/前3秒）× 留存（核心循环好不好玩）× 传播（分享钩子）**。吸量与传播后置，留存是当前主战场。肉鸽塔防 Build 构筑品类的"留存/好玩"可拆成五个支柱：

| 支柱 | 含义 | 检验标准 |
|---|---|---|
| **1. 决策质量** | 每一选都改变局面 | 三选一卡时有没有纠结感？"选哪个都差不多"是死亡信号 |
| **2. 构筑涌现** | 词条间的化学反应 | "A+B 超出预期"的组合存在吗？这是 Build 游戏的灵魂，也是玩家晒的素材 |
| **3. 爽感曲线** | 从求生到无双的反转 | 开局艰难守线 → 后期"我无敌了"（3~6 倍输出上限是这条曲线的护栏） |
| **4. 失败可读** | 死了知道为什么 | 玩家想"下次换个 Build 能过"，而不是"随机性坑我" |
| **5. 再来一局的钩子** | 流派探索欲 | 强度 ≈ 可成形流派的数量 |

**好玩是测出来的，不是想出来的。** 个人开发者验证三板斧（成本递增）：

1. **自测 20 局**：自己都不想再开的游戏，别人更不会开；
2. **"再开一局"测试**：死了/赢了瞬间的冲动是"再来一把"还是"算了"——肉鸽品类金标准；
3. **闭嘴观察法**：给朋友玩，**不问"好玩吗"**（问不到真话），观察行为：哪里皱眉、哪里走神、哪里放下手机、通关后有没有主动再开。要等 UI 可读性够了再做，否则"看不懂"会污染数据。

每次自测留意两题（最有价值的设计输入）：**哪个瞬间最爽**（要放大、做更多同类）？**哪个瞬间最想关掉**（留存漏斗的洞，优先堵——玩家流失不是因为不够爽，是某个瞬间烦到关掉）？

## 四、现状盘点：两个成形流派 = 两种爽感原型

| | 毒爆流 | 供电攻速流 |
|---|---|---|
| 构筑原型 | **传播型**（面状） | **造神型**（点状） |
| 化学链 | 橡皮筋弹射 → 全屏上毒 → 毒死 → 爆炸 → 波及旁边中毒敌人 → 连锁清屏 | 充电宝锁定攻击最高的吸管 → 攻速+35% + 25%暴击2倍 → 堆出"神级吸管" |
| 爽的心理 | "我放的毒在替我杀人" | "这根吸管是我养出来的" |

一个游戏同时提供两种不同方向的爽感（对照杀戮尖塔的毒贼/力量战），说明构筑空间不是一维的——**支柱 2 初步成立的硬证据**。

两个待检查的隐患：

1. **流派菜单长度**：能成形的流派若只有 2 个，第 3 局开始玩家就在重复自己 → 支柱 5 强度不足。盘点一下现有塔 × 词条里"玩家能主动追、追出来确实爽"的流派有几个。
2. **两派强度是否接近**：一派明显更强就会变成"唯一答案"，三选一纠结感死亡 → 支柱 1 崩塌。

设计细节的提醒：流派目前是系统顺着棋盘"喂"出来的（解锁条件 `hasTower` + `wave>=3`、权重 ×1.4）。方向对（保证追得到），但最好的 Build 游戏追求的是**"应验感"而非"喂饭感"**——玩家先拿到橡皮筋、自己产生"要是弹射能上毒就好了"的念头，下一波淬毒橡皮筋出现，玩家想"果然有！"。现有的 wave≥2 / wave≥3 分层投放（先原料后催化剂）已经在做这件事，继续保持。

## 五、竞品拆解：《赵云与阿斗》（2026.6 霸榜的文字合成塔防）

**事实**：蜜獾工坊 3~5 人团队，美术成本约等于零（汉字+水墨），2026 年 6-7 月霸榜微信小游戏畅玩榜/人气榜/PC 榜，纯广告变现。**几乎就是本项目路线的成功样本。**

### 五层爽点叠加

| 层 | 机制 | 设计要点 |
|---|---|---|
| 1. 赌博层 | 征兵抽卡（随机出兵种/金色字牌/铲子），**每次征兵成本递增** | "现在抽还是攒着抽"是持续决策张力；变动比率强化（与老虎机同构） |
| 2. 收集层 | 武将掉落**单字碎片**，"赵"+"云"凑齐且按正确顺序摆放才能召唤 | 汉字顺序本身变成玩法约束；收集品零绘画成本；三国 IP 自带强度幻想 |
| 3. 成长层 | 2 合 1 升星（merge 爽感）+ 格子有限、铲子随机出现 | **空间管理**成为第二决策轴 |
| 4. 对抗层 | 1V1 对称竞技守阿斗，阿斗 3~9 条命；武将技能、神兵符（绝境全队无敌） | 命条 = 翻盘窗口；"差一点输但最后翻了"是情绪最高点，被显式设计出来 |
| 5. 传播层 | "赵云救阿斗"全民梗 + 省级/全国地域排行榜 | 游戏名本身就是传播素材 |

情绪曲线：征兵（小期待）→ 合成（小满足）→ 凑齐召唤（中高潮）→ 技能翻盘（大高潮）——小爽点以秒计、大爽点以分钟计，密度极高，是"小游戏前 30 秒必须爽"的教科书执行。

### 与本项目的映射

| 机制 | 赵云与阿斗 | 本项目 |
|---|---|---|
| 随机出兵/塔 | 馒头征兵（成本递增） | 10 金币召唤（**固定价格**） |
| 合成 | 2合1 升星 | 合并 ✅ 已有 |
| 守护目标 | 阿斗（3~9 命） | 基地（6 命）✅ 同构 |
| 翻盘钩子 | 武将技能、神兵符 | **暂无** |
| 收集钩子 | 凑字召唤武将 | **暂无** |
| 构筑深度 | 武将+装备（较浅） | **词条 Build（独有，更深）** |
| 美术 | 汉字+水墨 ≈ 0 成本 | Graphics 占位 ≈ 0 成本 |

### 可直接抄的三项（B 类决策）

1. **递增召唤成本**：固定 10 金币 → 每次 +N，立刻多出"现在抽还是攒"的决策张力。一行数值改动，白捡一个爽点层。
2. **翻盘钩子**：玩家绝境时刻（基地剩 1 命被突破）缺一个"神兵符时刻"——比如稀有的"清屏冰冻"卡，术语表里预留的**主动技能 Skill** 正好落在这里。
3. **收集钩子**：流派从"堆词条"加一层"集齐感"——同流派集齐 3 个词条触发**流派觉醒**（称号 + 质变效果），即"凑齐赵云"爽感的 Build 版移植。

### 它投的两票

- **美术后置**最有力证据：用汉字当作战单位的游戏霸榜了，"极简符号风"甚至可作为本项目将来正式美术的候选方向之一；
- **品类机会**的直接证据：5 人团队在塔防这个最古老标签下 2026 年 6 月霸榜——塔防不是红海，无差异才是。

### 差异化定位

它比本项目会"勾人"（收集/对抗/传播层完整），本项目可以比它"耐玩"（词条化学反应的构筑深度它没有）。**吸量学它，留存靠自己。**

## 六、行动顺序汇总

```
把词条做出纠结感+化学反应（当前施工：cards/ 数据层实测）
→ 自测 20 局（记录最爽/最想关掉瞬间）
→ 修不爽的点（含上面三个可抄机制排期）
→ 朋友观察测试（闭嘴观察法）
→ 题材/美术吸量层（art-pipeline.md 阶段 2-3）
→ 分享钩子（晒 Build/晒战绩）
```

留存为 0 的游戏，吸量再强也是漏水的桶——前半程成立之前，后半程不投精力。
