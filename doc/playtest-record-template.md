# Demo 试玩记录表与评分标准

本文档用于量化描述一局游戏是否好玩、是否爽，以及问题来自数值、规则、发牌、反馈还是节奏。

当前阶段建议先连续测试 10 局：

- 顺势构筑 4 局：根据出现的牌决定方向。
- 强追流派 4 局：开局指定流派，观察是否有能力追出来。
- 混合构筑 2 局：只选择当前最强收益，不主动凑套装。

至少连续完成 3 局再调整数值，避免被单局随机结果误导。

---

## 一、先区分四种体验

### 1. 好玩

玩家需要判断、承担代价，结束后愿意尝试另一种选择。

### 2. 爽

某个瞬间力量明显释放，并且玩家能理解这是自己的构筑造成的。

### 3. 容易赢

不等于好玩，也不等于爽。全程没有压力的胜利可能很无聊。

### 4. 终于不倒霉

抽到等待已久的组件会带来释放感，但它不一定代表流派本身好玩。需要和真正的战斗爽点分开记录。

---

## 二、单局开始前

```text
局数：2
日期：2026-08-13
测试模式：顺势构筑 
预设目标流派：无
本局验证问题：如果进入控制爆破流，最多放置2座减速塔，并保证至少2座直接攻击塔，观察能否击败BOSS。
```

验证问题应尽量具体，例如：

> 如果进入控制爆破流，最多放置2座减速塔，并保证至少2座直接攻击塔，观察能否击败BOSS。

不要只写“测试平衡性”或“看看好不好玩”。

---

## 三、每波记录表

游戏中存在两套不同的选择系统，必须分开记录：

- 波次结束后的三选一强化。
- 花金币抽取的五张塔牌。

```text
波次：1
当前构筑方向：无 
当前成型阶段：有方向
当前核心组件：牙刷

敌人最远推进：1
本波压力：1 
基地剩余生命：6

波后强化三选一：治疗抑制、借款扩建、安全距离
波后强化纠结度：0 
最终选择：借款扩建
选择理由：成长

本波抽塔牌次数：3
本波想要的塔牌：锅铲
是否出现：否
没有出现时的替代选择：橡皮筋
为等待组件累计进行了几次无效抽牌：0

期待下一波发生什么：流派的
```

### 敌人最远推进评分

| 分数  | 表现        |
| --- | --------- |
| 0   | 敌人刚出现就被消灭 |
| 1   | 走过路径前段    |
| 2   | 推进到地图中段   |
| 3   | 接近基地      |
| 4   | 基地受伤或濒临失败 |

### 本波压力评分

| 分数  | 感受              |
| --- | --------------- |
| 1   | 完全没有危险，可以不看屏幕   |
| 2   | 轻松，但战斗仍值得观察     |
| 3   | 敌人明显推进，开始关心塔的发挥 |
| 4   | 危险，需要下一次选择解决问题  |
| 5   | 濒临失败或已经无法挽回     |

理想压力不是一直为1，而是反复经历：

```text
建立压力 -> 获得组合 -> 释放压力 -> 出现新威胁 -> 再次突破
```

### 波后三选一纠结度

| 分数  | 判断标准               |
| --- | ------------------ |
| 0   | 没有选择，某张明显最好        |
| 1   | 很快知道选什么，只看了一下其他牌   |
| 2   | 两张都想要，认真思考了几秒      |
| 3   | 三张都有明确价值，放弃任何一张都心疼 |

阶段目标：

- 平均纠结度为 1.5 至 2.2。
- 纠结度为0的次数不超过全部选择的三分之一。
- 纠结度为3一局出现1至2次即可。

纠结度过低说明选项没有竞争关系；一直为3则可能造成决策疲劳。

### 选择理由

| 类型  | 含义             |
| --- | -------------- |
| 生存  | 现在不拿可能会死       |
| 成型  | 补齐或明显推进核心组合    |
| 成长  | 当前较弱，但后期收益高    |
| 转型  | 放弃当前方向，进入另一套组合 |
| 通用  | 不影响流派方向的稳定收益   |

理想的三选一经常形成：一张救当前、一张补流派、一张赌未来。

## 四、流派成型时间点

每局记录三个时间点：

### 1. 方向出现

第一次感觉“这局可能走某套流派”。

示例：第2波获得冻结破甲，开始考虑控制爆破流。

### 2. 基础成立

至少两个组件开始相互配合，而不是各自独立工作。

示例：减速塔、牙刷和锅铲已经能共同触发控制爆破。

### 3. 质变完成

战斗方式发生肉眼可见的变化，而不只是数字略微上涨。

示例：供电奶茶吸管的第二次戳击必定暴击，第二击成为稳定爆点。

当前推荐节奏：

| 阶段   | 推荐出现时间    |
| ---- | --------- |
| 方向出现 | 第1至2波     |
| 基础成立 | 第3至4波     |
| 质变完成 | 第5至6波     |
| 最终验证 | 最后一波或BOSS |

第6波仍未基础成立，通常会让玩家感觉流派只存在于想象中；第2波已经完全质变，则可能导致后续选择失去意义。

## 五、爽点事件记录

每次出现明显释放、逆转或成型时记录一次。

```text
发生波次：
爽点类型：获取爽 / 成型爽 / 战斗爽 / 逆转爽
发生了什么：
触发条件：
我是否明确理解触发原因：是 / 否
画面结果：
战斗结果：
即时情绪：
爽度总分：
持续兴趣：1 / 2 / 3 / 4 / 5
```

### 爽度拆分评分

每项0至2分，总分10分。

| 维度  | 0分       | 1分     | 2分           |
| --- | -------- | ------ | ------------ |
| 因果  | 不知道为何触发  | 大概知道   | 明确是自己的构筑触发   |
| 反差  | 前后没有变化   | 有所提升   | 战局明显逆转       |
| 反馈  | 几乎看不出来   | 有数字或特效 | 动画、数字和敌群变化一致 |
| 规模  | 单个小效果    | 影响几个目标 | 一片敌人同时受到影响   |
| 稀缺  | 高频发生并已麻木 | 偶尔发生   | 等待已久的关键释放    |

| 总分   | 解释     |
| ---- | ------ |
| 0至3  | 几乎没有感觉 |
| 4至6  | 有效反馈   |
| 7至8  | 明显爽点   |
| 9至10 | 本局记忆点  |

### 区分获取爽与战斗爽

“终于抽到牙刷”属于获取爽或成型爽。还要继续记录牙刷参与战斗后是否真的产生清晰变化。

如果获取牙刷爽度7，但组合触发时战斗爽度只有3，说明玩家爽的是“终于不倒霉了”，流派自身的反馈仍然不足。

### 识别虚假爽感

如果第一次爆炸很爽，但之后每波自动清场且选择不再重要，应记录：

```text
第一次爽度：8
后续持续兴趣：2
原因：爆发反馈很强，但成型后失去危险与决策。
```

好的爽点应当让玩家感觉“因为我做对了，所以爆发”，而不只是数值足够大。

## 六、成型后体验

流派基础成立后，每波增加一项：

```text
成型后状态：继续构筑 / 补强数值 / 垃圾时间
下一次选择是否仍会改变结果：是 / 否
```

| 状态   | 含义                |
| ---- | ----------------- |
| 继续构筑 | 仍有两个以上值得考虑的发展方向   |
| 补强数值 | 组合完成，只是在叠伤害、攻速或范围 |
| 垃圾时间 | 无论拿什么都会赢，只等关卡结束   |

成型后最好还保留一次有意义的选择，例如扩大优势、修补弱点或针对最终威胁。

## 七、局末好玩度评分

每项1至5分，总分30分。

| 指标   | 核心问题         | 1分      | 3分        | 5分             |
| ---- | ------------ | ------- | --------- | -------------- |
| 选择意义 | 我的选择是否改变战斗结果 | 基本无影响   | 部分关键选择有影响 | 多次选择明显改变局面     |
| 构筑身份 | 最终阵容是否属于明确玩法 | 看不出方向   | 有方向但组合较松散 | 一眼能说明流派及运作方式   |
| 成长期待 | 是否期待下一张关键牌   | 没有期待    | 偶尔期待组件    | 全程知道自己在寻找什么    |
| 风险回报 | 投资组合是否承担真实风险 | 无风险或无回报 | 有取舍但不明显   | 放弃即时收益并获得明显回报  |
| 失败归因 | 输后是否知道如何改进   | 只觉得随机坑我 | 有大致猜测     | 能指出具体错误并形成下局计划 |
| 再开意愿 | 是否想立刻再玩一局    | 不想继续    | 休息后可能继续   | 立刻想验证新策略       |

### 总分参考

| 总分    | 判断           |
| ----- | ------------ |
| 24至30 | 核心体验成立       |
| 19至23 | 有趣，但存在明显断点   |
| 14至18 | 局部有爽点，整体构筑较弱 |
| 6至13  | 主要依靠随机或数值推动  |

总分主要用于横向比较不同测试局，不用于证明游戏“客观上有多好玩”。

## 九、问题描述句式

不要只写：

> 奶茶流弱，不爽。

推荐写成：

> 第3波已有充电宝、两根奶茶吸管和核心供电，但敌人最远推进仍为3。攻速变化肉眼不明显，击杀速度没有形成前后反差。基础组合成立，但没有产生阶段性奖励。爽度2，问题更像数值和反馈，而不是获取难度。

统一句式：

> 在【时间点】，因为我选择了【卡牌或塔】，我期待【结果】；实际发生了【结果】。我的感受是【爽、紧张、失望或无所谓】，原因可能属于【数值、规则、发牌、反馈或节奏】。

## 十、三局小结模板

每完成3局再进行一次小结：

```text
测试局范围：第__局至第__局
胜利次数：
平均好玩度：
平均波后强化纠结度：
平均基础成立波次：
平均质变波次：
平均无效抽牌次数：
平均垃圾波次数：

重复出现的低纠结选择：
重复出现的成型前死亡：
重复出现的成型后垃圾时间：
重复出现的关键牌等待：

当前最可信的问题：
暂时不能下结论的问题：
下一组三局只验证什么：
```

优先处理连续出现至少3次的问题：

1. 连续出现的低纠结选择。
2. 连续出现的成型前死亡。
3. 连续出现的成型后垃圾时间。
4. 流派方向已经出现，但关键塔牌长期不出现。

如果玩家失败后能明确说出下一局想改变什么，说明游戏产生了策略想象；如果只能说“希望下次发牌更好”，说明玩家控制力不足；如果觉得“照样选就行”，说明构筑决策已经失效。
